# Context Memory Query (情境记忆与时空切片检索技能)

## 一、 技能目标
用户使用 SunMate 随身录音卡和手机通知，所有的关键决策、灵感碎片与对话都会沉淀在本地工作空间与 `MEMORY.md`。
本技能负责**“精准召回与上下文联想”**：
1. **时间范围定位**：根据用户的口头提问（如“昨天上午”、“周三下午”、“上个月关于协议的讨论”），推断对应的绝对时间区间；
2. **多维交叉比对**：在沉淀的随身日志、会议纪要库及系统通知流中，检索匹配的事件块；
3. **事实忠实归纳**：以事实为本，提取真实的对话原句、发言人、结论与行动项，拒绝无根据的幻觉。

## 二、 执行工作流
1. **时间推断**：解析用户查询中的相对时间词（昨天、上周、刚才、今天下午），对应为精确日期；
2. **记忆库匹配**：
   - 检查 `~/.hermes/memory/` 或当前工作目录下的 `MEMORY.md`；
   - 检查历史会议纪要归档；
   - 检查 `sunmate_app` 记录的时间线事件；
3. **精准呈现**：
   - 给出匹配事件的具体发生时间点；
   - 标明是“随身录音发言”还是“手机通知”；
   - 给出上下文背景与后续决议。
