# SunMate 接入诊断

先读取 [数据契约](references/data-contract.md) 中诊断信息约定。所有结论附实际检测依据，按“通过/失败/未测试/不可用”分别报告。

新版本可使用 `sunmate.reference.v1` 精确归档引用，优先按数据契约的引用流程调用 sunmate_get 并核对库身份；不要因消息没有重复附正文而误报缺资料。普通历史查询可使用实际已启用的 sunmate_search/get/stats/sync_status，不能假定工具已经安装或手机已全量同步。

- 确认所选 Hermes profile 和实际配置；从该部署的 API 配置/运行环境获取原生地址、端口和模型。没有配置时，先核对当前安装版本的官方默认值；仍不能确认就询问，不猜主机或端口。
- Token 使用目标 profile 的 API_SERVER_KEY，不是模型提供商密钥。不打印、不回传密钥，不读取与诊断无关的凭据。带 Token 的请求不跟随重定向；非回环访问应使用 HTTPS 或已明确保护的传输。
- 区分服务可达、鉴权通过和模型可推理。缺失/错误 Token 应被拒绝，正确 Token 才能读取 models。用户请求连接测试时发一次无业务副作用的随机文本回显请求，检查成功结束状态；仅健康接口或 HTTP 成功不能证明智能体可用。
- 用户要求流式诊断时，另检查完整 SSE 事件、结束标记与 error/cancelled 状态；不要把工具进度当最终回复。不因超时自动重发可能产生业务副作用的请求。
  离线包支持 `setup_hermes.sh --check --check-stream`：额外一次真实随机文本流式回显，检查正文、finish_reason=stop 和 [DONE]，不打印正文。它不主动执行天气查询等工具，因此回显成功不等于工具功能已验证；需用户授权单独测试业务。没有加此选项时如实标注 SSE 未验证。
- 能力发现接口存在时检查五个 SunMate 技能是否被发现及相关工具是否启用；接口不存在时标为未验证，不能宣称全部技能已生效。
- ASR 仅在实际配置且本次需要时检查；未部署则跳过。无音频测试不能声称转写或说话人识别成功。
- 服务器本机可达不等于手机可达。回环地址不能作为手机端点；反代路由必须保留 profile 前缀。没有手机侧结果时标为“手机未验证”。智能体不能凭服务器网络测试判断手机蓝牙/通知授权状态。
- 诊断不修改核心配置、安装依赖、重启服务或终止进程。确需修复时先给出依据与具体操作，按用户授权执行；失败如实返回，不生成成功替代内容。
- 分别报告安装文件、技能发现、普通推理、SSE、工具业务、手机可达和持久归档；不能将某一层通过合并成“全部正常”。通知回传计数/未读数只能依据 App 提供的结果，服务器自检不能代替手机采样。
