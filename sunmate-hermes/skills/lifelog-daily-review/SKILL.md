# Lifelog Daily Review (全天随身时光机成长复盘与记忆沉淀)

## 一、 技能目标与第一性原理

全天 24 小时随身录音（低功耗声控 VOR）会产生大量零碎的对话、自言自语和环境声，伴随手机通知流水。
本技能的职责不是将琐碎音频原样复述，而是作为**“认知过滤器与第二大脑教练”**：
1. **去粗取精**：过滤掉点餐、寒暄、口癖等噪音信息；
2. **时空对齐**：将口头对话与同一时间段的手机通知（微信、邮件、日程）交叉印证；
3. **输出成长画像**：从“认知决策”、“沟通倾听”、“时间精力”三个维度评估用户当天的表现，并给出明确的提升建议；
4. **记忆持久化**：将当日的关键认知、重要承诺与决策增量沉淀到用户的长期记忆库 (`MEMORY.md`) 中。

---

## 二、 严格执行工作流

### Step 1: 时空切片聚类与噪音过滤
接收 App 传入的 `【今日语音时间轴流水】` 和 `【今日手机重要通知】`：
- **过滤**：丢弃纯碎念、验证码短信、打车外卖等低价值信息；
- **聚合**：将时间相近（30分钟内）的语音讨论与日程通知聚合为一个【时空事件块】（例如“上午 10:00-10:45 架构解耦评审”）；
- **说话人识别**：结合 MOSS-ASR 的 Speaker 标签，识别哪些是用户自己的发言，哪些是外部输入。

### Step 2: 多维分析与成长画像评估
按照以下四大维度进行严谨分析：

1. **认知与决策质量评估**：
   - 今天用户作出了哪些关键判断与技术/业务决策？
   - 决策是否有事实依据？是否展现了第一性原理？
   - 是否有未经深思熟虑的冲动承诺？
2. **沟通表现与情绪得失**：
   - 用户的倾听比例与发言比例是否平衡？
   - 表达逻辑是否精炼、能否迅速促成讨论收敛？
   - 是否出现情绪波动或防卫心理？
3. **时间与精力分布**：
   - 统计【深度思考/架构设计】、【业务推进会议】、【碎片被打断沟通】、【日常琐事】的估算耗时占比。
4. **针对性能力提升建议**：
   - 提炼 1~2 条明确、可落地的明日行动建议（例如“在明天下午的沟通中，尝试在发言前先复述对方观点，提升共识效率”）。

### Step 3: 输出结构化报告
向用户输出排版优雅的 Markdown 报告：

```markdown
# ☀️ SunMate 今日全天成长复盘与认知画像 (YYYY-MM-DD)

## 一、 核心认知与关键决策
- **[重要决策]** ...
- **[思维亮点]** ...

## 二、 沟通表现与倾听得失
- **表达收敛度**: ...
- **倾听与反馈**: ...

## 三、 时间与精力分布画像
- 🎯 核心深度思考: XX%
- 🤝 业务与会议沟通: XX%
- 📱 碎片通知与打断: XX%

## 四、 🌱 明日针对性能力提升建议
> **核心改进动作**: ...
```

### Step 4: 写入长期记忆 (Write to Memory)
如果用户当天的讨论中产生了重要人生决策、新知识沉淀或长期项目结论，调用 Hermes 记忆工具将其写入 `MEMORY.md`，保证第二大脑的持续成长！
