# SunMate 1.0.21+22：首次添加与登录保存

2026-10-18。用户授权本版升级、检查后推送main构建并下载IPA，同时要求保存登录、保持HAL与私有端点、不自动解绑或覆盖旧密钥。

## 本版行为

- 登录后可选择已有账号设备恢复，也可「添加新录音卡」；空列表允许首次添加。新流程绑定当前账号会话、所选外设的新鲜完整广播SN、实际Telink GATT与设备挑战，复用真实验机、X25519/AES、云绑定链路。
- 已有或重复账号SN不从新入口重新协商；本机已有业务key时保留并引导已验证身份重连。没有自动unbind、恢复出厂或覆盖不同旧key。
- 广播身份在提交系统连接前取快照，避免配对等待后扫描缓存过期/消失导致丢SN。
- 官方登录Token及用户ID写入独立系统安全存储条目：iOS Keychain的本机条目，Android沿用已有加密安全存储。关闭页面只清内存，重新打开恢复会话并通过正常设备列表请求确认；手机号、验证码、设备共享密钥不写入此登录条目。
- HTTP401清除当前失效登录与账号内存资料，要求用户重新登录；403/429/网络或服务器故障保留登录以便重试，不自动获取验证码。未猜测厂商refresh接口或绕过认证。
- 「退出官方账号」删除登录条目，保留录音卡的业务密钥；迟到登录、保存、设备列表和旧实例401不能覆盖/删除新登录。安全存储失败有脱敏说明，不降级明文存储。
- 原生蓝牙连接选项、HAL多驱动与私有MOSS-ASR/Hermes路径不变。pubspec、首页/设备设置、复制诊断及对应断言均为1.0.21+22。

## 安装后测试顺序

1. 按此前自签方式安装，首页与复制诊断均应显示1.0.21+22。旧版只在内存中登录，升级后首次仍需正常登录一次；本版登录成功后应显示「登录状态已安全保存」。
2. 关闭连接页、重新打开，再退出并重开App，确认自动恢复账号且不自动发短信。刷新只读取设备列表；若服务器明确返回401，再正常登录。
3. 关闭安卓蓝牙。账号中已有卡片时选择已有记录；只有账号列表中没有该卡时，使用「添加新录音卡」。保留当前资料，不为了试入口反复解绑或重置。
4. 遇系统配对/通知请求时正常确认。业务成功后保持一分钟，用实体按键录一段话，再断开重连测试本机身份；转写与智能体仍使用私有端点。
5. 失败时复制本版蓝牙/账号脱敏诊断。若仍停在系统connecting且无GATT，说明尚未执行业务验机，不能将其归因为共享密钥被拒绝。不要发送验证码、Token、HMAC或密钥。
