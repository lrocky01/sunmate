# SunMate 1.0.11 手机测试说明

安装本次 GitHub Actions 生成的 IPA 后，首页顶部应显示 **v1.0.11+12 · 蓝牙配对与诊断**。本版保留 HAL 与私有 MOSS-ASR/Hermes 端点配置，重点验证系统配对、ANCS 授权及真实 GATT 通道。

1. 暂时关闭官方 App 对这张录音卡的连接，让设备可广播；保持现有系统/厂商绑定，不要先恢复出厂。
2. 在 SunMate 搜索并选择 C·ONE-4552。系统出现配对与通知授权时按自己的意愿处理。已记住配对/通知授权的 iPhone 可能不会再弹窗。
3. 若显示“链路已连接，业务待鉴权”或“等待合法业务鉴权”，这表示蓝牙链路与业务验证已分开记录；没有合法厂商密钥时不会再发送假鉴权或显示全功能就绪。
4. 保持前台至少 60 秒，记录是否断开、设备灯状态，以及两个系统弹窗是否出现。可再做一次后台切换与返回。
5. 无论成功或断开，打开首页“蓝牙状态与诊断日志”，点击右上角复制按钮，将日志发回本聊天。诊断页中的 ANCS、完整 GATT、阶段、时间轴、原生错误码是下一步判断的依据。

“取消并断开蓝牙连接”会取消当前尝试；“清除设备记录”仅清除 App 保存的 ID。系统 bond 和通知授权仍需在 iPhone 的蓝牙设置中管理。关闭 ANCS 请求开关只影响下次连接，不会代替系统撤销已有授权。

本版不把未验证的音频通知当作可播放 Opus，也不承诺通知正文已可透传。硬件录音、音频导出与 ASR 联调应在业务鉴权和帧格式验证后继续；手机麦克风驱动维持原实现。

构建检查包括 Flutter 分析、协议/连接状态/原生桥接回归测试和 iOS 编译。模拟测试无法证明这张实体卡的配对弹窗或无线稳定性，须以本次手机日志为准。
