# SunMate 1.0.22+23 手动账号解绑测试

## 改动与边界

- 在登录后的账号设备记录下新增「解绑账号设备」。仅当前成功读取的唯一记录、真实MAC及可恢复密钥齐全，且未连接、未发起连接、未录音/暂停时可用。
- 二次确认包含设备名称、SN及影响。取消零请求；确认后先将账号ID/SN/协议/MAC/共享密钥/可选UUID独立归档到系统安全存储，每次新增条目并读回核对，不覆写活动BLE密钥或登录条目。归档不是卡片身份验证结果。
- 只向官方正常账号接口POST `/api/device/toc/externalDeviceBind/unbind`，body为账号记录的`deviceId`和`mac`；不发送共享密钥、验证码或iOS UUID，不调用HAL清卡/解绑/重置。
- 防重复提交、过期选择、备份期间账号或硬件状态变化；既有业务会话失效。服务器接受后重新读取列表，SN仍在或列表不可用时保持待核对，禁用连接/添加，只允许重新读取，不自动重发。
- 业务拒绝不清理；超时/HTTP错误不冒称完成，正常列表重新对照后由用户决定后续操作。401按已有登录失效逻辑处理，保留录音卡密钥和归档。
- 首页、录音卡设置、诊断和pubspec同步1.0.22+23。HAL、多驱动、私有MOSS-ASR/Hermes端点与旧密钥保护保持原实现。登录安全保存沿用1.0.21逻辑。

## 真机验收步骤

1. 沿用此前自签方式安装；确认首页及诊断显示1.0.22+23。优先覆盖安装以保留原签名下的系统安全存储，不卸载重装。
2. 关闭安卓蓝牙，保持卡片不连接；SunMate打开账号设备页应自动恢复现有有效登录并读取列表，登录失效才手动登录。
3. 找到目标SN，点「解绑账号设备」，核对名称/SN/影响。先取消一次确认未执行，再在确认已备份未同步录音后自行决定是否正式提交。
4. 提交后须看到「已确认账号列表移除目标SN」，才走「添加新录音卡」。如显示待核对，点「重新读取我的设备」，不要连续重复解绑。若系统保留配对，按提示自行处理iPhone系统配对。
5. 重新扫描连接，处理实际出现的系统弹窗。须真实验机、协商/AES回执成功才能报告业务就绪。保留旧密钥保护；如提示不同旧密钥，停止并反馈，不能覆盖。
6. 保持一分钟并用卡片按键录音，验证私有ASR实际收到并返回转写。若失败，提供本版蓝牙及脱敏账号诊断，不提供任何凭据。
