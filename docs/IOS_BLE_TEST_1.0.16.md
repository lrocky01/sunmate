# SunMate 1.0.16+17：先登录，再连接录音卡

本版把连接入口改为「登录自己的官方账号 → 读取账号设备 → 选择目标 SN → 搜索并连接蓝牙」。不再要求先连上卡、取得 SN 后才能登录。短信与登录沿用用户已验证成功的 App 同源渠道 3。HAL、多驱动与私有 MOSS-ASR / Hermes 直连保持原样。

## 连接流程

若设备发来首次验机挑战，本版通过已登录账号提交当前 encrypted/mac/sn 至官方 /check，收到真实答复后发送 verifyResult，与卡片完成 X25519 公钥交换。新密钥先保存到安全存储，再按官方 /bind 契约同步到自己的账号，随后仅重连一次，通过新一轮 AES 身份挑战才报告连接成功。账号返回的合法 uuid 才复用，缺少时不编造。

若本机已有合法密钥，直接走挑战验证；若账号提供可恢复密钥，则必须在实际观察到 SN 且发现的协议匹配后才恢复。已有不同密钥不自动覆盖。账号会话、验证码不持久保存，日志不包含 HMAC、共享密钥或会话。

本次 APK 核对确认的是 Android 业务代码顺序。iOS 系统配对与 ANCS 授权是另一层，尚未取得官方 iOS 完整握手证据。登录优先不能保证消除系统连接前的等待，也不能保证两个系统弹窗一定出现。

## 手机测试

1. 安装后核对首页与蓝牙诊断显示 **1.0.16+17**。关闭 Android 的蓝牙，避免后台占用；卡片保持开机，不解绑、不恢复出厂。
2. 点击连接录音卡，在新入口自行输入手机号及新验证码，登录并读取账号设备。选择目标 SN（SZ12001261804552），再连接扫描到的 C·ONE-4552。不要将验证码或账号会话发到聊天。
3. 观察系统配对/通知弹窗是否出现；已有系统配对时可能不重复弹出。记录有没有进入 GATT、厂商验机、账号同步或本地挑战阶段。
4. 如仍停留在系统连接阶段，等待进度应每 10 秒更新，并在默认 90 秒截止后请求取消。也可以点取消；取消可能仍需系统确认，界面不将超时取消当作物理链路已释放。
5. 首次方式仍卡住时，取消后在搜索页右上「蓝牙连接方式」选择 **仅录音连接**，再重试。这只改变 RequiresANCS 请求选项，业务身份验证仍执行。记录两种方式的实际状态及弹窗差异。
6. 连接成功后至少保持两分钟，用卡片物理按键尝试实时录音，结束后检查私有 ASR 结果。后续可用「使用本机已验证身份重连」，不必每次登录官方账号。
7. 若失败，从蓝牙诊断复制完整日志；重点保留 connect_requested / state、等待秒数、断开原因、官方验机或同步账号绑定的 HTTP/业务码。不要发送任何凭据或共享密钥。

首次协商可能生成并同步新的设备身份。官方 App 在其它手机保存的旧本地身份如何刷新仍待实测，不保证多台手机同时连接。/check 与 /bind 契约已按官方代码实现，但本账号的真实服务接受结果、iOS 弹窗和实体稳定录音仍需以上测试确认。
