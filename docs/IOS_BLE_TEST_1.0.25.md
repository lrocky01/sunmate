# SunMate 1.0.25+26 录音卡设置测试

本版补齐会议录音双击/三击触发方式选择、会议录音呼吸灯开关、当前设置读取及修改后回读确认。仅在当前Telink连接通过真实AES后读取；能力2001/3001分别开放按键/灯选项。录音中、录音状态未知、未读到有效设置、缺能力时禁止修改。写入完成不当作保存成功，超时不自动重写或假装回滚。

本版同时包含此前已获授权并完成本地回归的二进制实时录音开始/结束事件、受控自动重连、录音卡管理页和密码加密备份入口。保持真实AES、旧密钥保护、HAL多驱动、现有私有ASR/Hermes直连，不自动解绑或重新协商。长录音仍未实现完整文件同步/回放，不把长录数据冒充实时语音。

## 安装与连接

1. 沿用此前相同Apple ID/签名方式，自签后覆盖安装，保留App数据、Keychain、系统配对及账号绑定；不卸载、解绑、忽略设备或恢复出厂。确认首页和蓝牙诊断为1.0.25+26。
2. 关闭安卓蓝牙，退出iPhone官方App。已有已验证身份可自动连接；否则使用已有卡片的“继续验证”。不需要为测试重新首次绑定或获取短信。
3. 确认诊断显示链路true、业务就绪true、设备业务已验证，再进入“录音卡设置与诊断→录音卡管理→录音设置”。若连接失败或提示身份/密钥冲突，停止并保留诊断。

## 当前值与双/三击

1. 等待“已读取卡片当前设置”；若未读到或超时，点“读取卡片设置”，不要按手机默认值猜当前配置。
2. 在卡片停止录音时选“三击”，等待“已保存，卡片回读已确认”。保存未确认时先重新读取，不连续重复写入。
3. 连续三击一次，等约5秒再三击一次，确认长录开始、结束；按实际当前选择停止录音后再修改设置。保留这轮诊断，用来核对长录状态。
4. 停止后切回“双击”，等待回读确认，再按同样方式双击开始、双击结束。另一种手势是否不再触发，仅在确认未录音时做一次对照，不混按手势。
5. 如指示灯或界面显示仍在录音，先用本轮已确认有效的触发方式结束，勿在录音期间改设置。

## 呼吸灯

1. 停止会议录音后关闭“会议录音呼吸灯”，等待回读确认，再用当前选定手势开始约5秒会议录音，观察灯是否关闭；结束录音。
2. 停止后开启呼吸灯，等待回读确认，再录约5秒观察并结束。实际灯效及关闭范围以本卡测试为准，不因开关回读成功就宣称全部状态灯效果已验证。
3. 退出再进入录音设置，点读取，核对值是否保持。后续可单独验证卡片断电后的持久性；本轮不要求重置卡片。

## 反馈内容

请发本版完整蓝牙诊断，并分别说明：当前值是否读出、双/三击各是否能启停、灯开关是否回读成功及实际变化。诊断只提供安全统计，不发送密码、验证码、Token、共享密钥、备份文件或原始HCI。

按键与灯光测试不需要ASR/Hermes。长按即时语音可另测音频通知/字节/帧统计；会议长录目前不等于已有App内音频文件或转写结果。系统配对及通知授权可以复用，不要求重新弹窗。
