# SunMate 1.0.24+25 iOS 恢复入口测试

## 本次改动

- 增加系统已连接录音卡及本机密钥已保存、身份待验证的恢复入口，使用现有 BLE 插件查询系统设备，与扫描结果去重；不伪造广播或信号强度。
- 安全存储保存业务密钥后记录不含密钥的身份路由；旧安装仅在系统 UUID 下的本机密钥与所选账号的唯一 SN/协议资料一致时迁移。点击接入前重新校验，拒绝身份冲突、不同旧密钥及账号变化。
- 「继续验证」仍需本次真实 AES 挑战通过，系统已连接和历史记录不代表业务就绪。保留真实厂商验机、X25519 协商、iOS 整数 isIos: 1、旧密钥保护和已有首次附加重连策略。
- HAL、多驱动及私有 MOSS-ASR/Hermes 直连保持；不自动解绑、清系统配对、重置卡片或覆盖旧密钥。首页、录音卡设置、诊断和包版本统一 1.0.24+25。

## 当前问题的边界

上次首次验机、密钥保存和云同步已成功；之后 SunMate 附加重连没有收到新的身份挑战，所以未启用录音。物理连接或订阅状态复用仍需真机报文确认。本版补齐已经保存密钥却没有恢复入口的缺口，不保证硬件一定重新发出挑战，也不降低 AES 成功门槛。

## 手机测试步骤

1. 沿用此前个人自签方式，用相同签名覆盖安装，保留 App 数据、安全存储、当前账号与系统配对。确认首页和诊断均为 1.0.24+25。
2. 关闭 Android 蓝牙，退出 iPhone 官方 App；保留当前卡片状态。不要主动解绑、忽略设备、清空数据或重新协商密钥。
3. 打开录音卡连接设置。已有账号时选择账号中的卡片；如果系统蓝牙已连接，查看新增的系统已连接候选，点「继续验证」。若先显示本机已保存但待验证的身份，也可从该入口继续。
4. 本机密钥存在只表示有恢复材料，界面仍应等待真实身份验证。若提示密钥不同、身份不匹配或需要解绑，停止并保留诊断，不覆盖旧密钥。
5. 业务验证成功后保持连接 5 分钟，用卡片按键录一小段话，确认私有 ASR 转写及结束录音，再检查正常重连。
6. 若没有候选、仍等不到挑战或录音失败，请发本版完整蓝牙诊断及脱敏账号诊断，并说明系统蓝牙状态；不发送验证码、Token、密钥或原始抓包。系统配对或通知授权可复用，不要求每次再次弹窗。
