# SunMate 1.0.14+15：账号设备接口格式修复

本版修复 1.0.13+14 在读取官方绑定时发送裸 Token 的问题。已知设备接口公开响应声明 Bearer 认证；新版使用登录所得真实 Token 加一次 Bearer 前缀，既不猜 Token，也不自动尝试其它登录渠道。HAL、私有 MOSS-ASR / Hermes、卡片现有绑定不变。

## 手机步骤

1. 按原自签名方式安装新版，确认首页显示 1.0.14+15。保留卡的官方绑定，退出官方 App，先让 SunMate 连接一次并取得设备 SN。
2. 蓝牙诊断 → 通过自己的官方账号恢复设备绑定，在手机重新登录；旧页面会话没有持久保存，不能直接复用上次登录。手机号和验证码不发到聊天。
3. 读取列表成功后，只恢复 SN/协议匹配的卡。随后仍须收到本次设备身份挑战成功回执，才算完成业务连接。再按 [完整连接/录音步骤](IOS_BLE_TEST_1.0.13.md) 测试。
4. 若读取仍失败，点击账号页面新增的“复制账号诊断（不含凭据）”，提供该文本和页面提示。诊断仅包含请求阶段、HTTP 状态、数字业务码及服务器是否声明 Bearer，不包含手机号、验证码、Token、共享密钥、服务端错误正文或 realm。

HTTP 401 表示凭证未被接受，HTTP 403 表示请求被拒；仅凭这些状态仍不能断言必须购买 SDK 或可以跨渠道访问。新版没有自动尝试更换渠道、伪造官方设备标识、解绑或绕过权限。整体目标仍取决于真实账号及硬件测试。
